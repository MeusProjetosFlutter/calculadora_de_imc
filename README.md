## Calculadora de IMC

Aplicativo mobile desenvolvido com **Flutter e Dart** que permite calcular o Índice de Massa Corporal (IMC) a partir das informações de peso e altura fornecidas pelo usuário.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do Flutter, gerenciamento de estado e manipulação de dados inseridos pelo usuário.

## Funcionalidades

- **Cálculo de IMC:** calcula automaticamente o Índice de Massa Corporal.
- **Classificação do resultado:** apresenta a classificação de acordo com o IMC calculado.
- **Validação de dados:** verifica se os campos foram preenchidos corretamente e se os valores informados são válidos.
- **Suporte a números decimais:** aceita tanto vírgula quanto ponto como separador decimal.
- **Identificação visual:** altera a cor do resultado de acordo com a classificação do IMC.
- **Limpar campos:** permite reiniciar a calculadora para realizar um novo cálculo.

## Tecnologias utilizadas

- **Flutter:** framework utilizado para o desenvolvimento da interface mobile.
- **Dart:** linguagem de programação utilizada na implementação da lógica da aplicação.
- **Material Design:** componentes visuais para construção da interface.

## Conceitos praticados

- StatefulWidget e gerenciamento de estado com `setState()`.
- TextEditingController para manipulação dos campos de entrada.
- TextField para captura de informações do usuário.
- Validação de dados e tratamento de exceções com `try/catch`.
- Estruturas condicionais (`if`, `else if` e `else`).
- Manipulação de Strings e conversão de valores com `double.parse()`.
- Personalização de componentes com `BoxDecoration`, `TextStyle` e `ElevatedButton`.
- Organização de código utilizando métodos e classes.

